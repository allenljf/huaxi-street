## 評分與長期用途

詳見 ../../research/strategy-and-hosting-2026-11-06.md 的提案，實作時以獨立規則表固定全部條件、優先順序及邊界，再寫測試。

第一版研究權重：長期均線40%、252日高點回落25%、RSI/KD/布林進場時機25%、MACD10%。黃金交叉不和均線重複計權。ADX/DMI和ATR做風險提示與濾網；CNN/VIX暫不加入核心分數。

買與賣分別計算，低買分不等同賣出；分數不是獲利機率或基本面估值。長期下跌趨勢限制機動加碼等級。高等級要求不同指標組支持、連續新交易日確認；同日重跑與休市不累計確認日。單次交叉事件與維持狀態分開顯示。

正二獨立標示，顯示ETF與追蹤基準的關係，無一般大盤高分即長期加碼正二的推論。第一版只給觀察支持度與檢查再平衡提示；無持倉資料，不輸出買賣張數，不串接券商或自動下單。

先完成可重現計算與回測，以相同現金流的固定投入和簡單均線法比較，計入成本、配息和現金閒置，採樣本外時間區段。不得以昨日收盤算今日訊號又假設昨日收盤成交。可交易台股商品做投資組合回測；海外指數先做訊號後報酬分析，不偽裝成可成交商品績效。結果不足以支持超額表現時，照實標示研究規則。

為讓回測可規劃，採以下由設計者提出的研究政策，不需使用者提供真實資金：每個非槓桿台股商品單獨模擬，每月首個交易日入金10,000元；80%核心於入金後首個允許交易時段投入，20%機動現金累積。每週首個交易日08:00檢查最近可用訊號，確認加碼分≥7且通過濾網時投入全部機動現金；各筆機動現金滿3個月即於下一個週檢查投入，現金利息設0。未批准最終數值前均標研究示例。基準固定投入為同日投入全額；均線基準採相同80/20現金流、機動條件改為收盤>SMA200且SMA200上揚、同樣3個月期限。第一版研究政策不實際減碼，減碼分僅呈現觸發後報酬與回撤分布；槓桿商品也僅做訊號分析。這些限制須在結果頁明示，避免暗示已驗證完整買賣策略。

## 排程與可靠性

依原始要求預設台灣週一至週五08:00啟動，UTC `0 0 * * 1-5`；增加週六以涵蓋美股週五收盤為精靈可選項，尚未視為使用者批准。08:00啟動不保證同時完成，網站呈現實際完成時間。支援手動重跑。

按各市場日曆判定最近完成時段；有限重試、休市標示、過期提示、保留最後成功快照。失敗不填0、不把舊行情當新訊號。發布前驗證結構與內容；完整網站產物一次部署，抓取原始行情不得混進公開artifact或日誌。持久資料保存方式由實作者依來源權限選擇，不能把Actions快取當唯一存檔。

## 部署精靈

採wizard技能範本，以Mac可執行的bash為第一個目標，放scripts/作可重複設定入口。由程式完成的建置與設定不要求人手複製。

| 階段 | 使用者操作／取得值 | 寫入位置 | 是否機密 |
|---|---|---|---|
| 1 環境與登入 | 透過GitHub CLI瀏覽器登入 | CLI本機憑證存放 | 是，不寫進repo |
| 2 專案 | 選擇或建立repo，輸入站名 | owner/repo非機密設定 | 否 |
| 3 網站與排程 | Pages部署設定、選擇是否週六執行 | repo設定與workflow | 否 |
| 4 選用資料憑證 | 僅為實際選定來源取得必要金鑰 | GitHub Actions Secrets | 是，隱藏輸入 |
| 5 首次更新 | 啟動workflow、確認更新結果 | Actions執行記錄 | 否 |
| 6 完成 | 開啟網站、顯示資料缺口和重跑方式 | README及網站狀態 | 否 |

標準GitHub Pages部署優先使用workflow的GITHUB_TOKEN，不要求使用者自行建立PAT；GitHub登入授權與任何其他服務金鑰不貼到聊天。精靈建立repo、推送、公開部署前顯示具體目標並由執行精靈的人確認。

## 驗收與實作順序

來源可行性驗證→規則與測試→回測報告→靜態網站→排程與精靈→實際部署驗證。驗收含分割、無波動序列、交叉邊界、缺漏、休市、不同時區、同日重跑。精靈做語法及靜態檢查；使用者執行登入與部署流程。

資料、圖形樣式、套件、檔案結構等可逆工程選擇由實作者決定；免費範圍以外的帳單、全站公開發布與額外帳號服務不自動擴充。網站使用免費平台網址，不需要自購網域、朋友名單或個人投資金額。
